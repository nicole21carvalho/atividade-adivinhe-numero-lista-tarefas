# Atividade 1 - Adivinhe o Número

## Objetivo

Desenvolver um programa Node.js que gera aleatoriamente um número inteiro entre 1 e 100 e permite que o usuário tente adivinhar o número.

O programa fornece dicas:
- se o número secreto é maior;
- se o número secreto é menor.

## Como executar

No terminal, execute:

```bash
node adivinhe.js
```
