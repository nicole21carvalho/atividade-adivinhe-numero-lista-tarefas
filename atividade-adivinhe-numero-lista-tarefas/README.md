# Atividade - Adivinhe o Número e Lista de Tarefas

Este projeto contém as duas atividades solicitadas no material da aula.

## Atividade 1 - Adivinhe o Número

Programa em Node.js que gera aleatoriamente um número inteiro entre 1 e 100.
O usuário tenta adivinhar e o programa informa se o número correto é maior ou menor.

## Atividade 2 - Lista de Tarefas

Aplicação web simples com HTML, CSS e JavaScript para:
- adicionar tarefas;
- marcar tarefas como concluídas;
- remover tarefas da lista.

## Como abrir no VS Code

1. Extraia o arquivo ZIP.
2. Abra o VS Code.
3. Clique em `File > Open Folder`.
4. Escolha a pasta `atividade-adivinhe-numero-lista-tarefas`.

## Como executar a Atividade 1

Abra o terminal na pasta do projeto e execute:

```bash
node atividade-1-adivinhe-o-numero/adivinhe.js
```

## Como executar a Atividade 2

Abra o arquivo:

```text
atividade-2-lista-de-tarefas/index.html
```

Você pode abrir direto no navegador ou usar a extensão Live Server.
