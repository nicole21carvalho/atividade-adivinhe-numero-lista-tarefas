# Atividade 2 - Lista de Tarefas

## Objetivo

Criar uma aplicação web simples usando HTML, CSS e JavaScript para gerenciar uma lista de tarefas.

## Funcionalidades

- Adicionar novas tarefas;
- Marcar tarefas como concluídas;
- Remover tarefas da lista.

## Como executar

Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no VS Code.
